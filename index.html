02

What it does

FILESWAV in, WAV out

A hand-written RIFF parser that reads 8, 16, 24 and 32-bit PCM and 32/64-bit float, mono or multichannel, and skips chunks it doesn't need. Saves 16-bit PCM.

EDITINGCut, crop, mix

Crop, cut, append, overlay another file at any time, insert silence, mix down to mono. Stereo and mono clips are matched automatically.

EFFECTSShape the sound

Volume, normalize, reverse, fades, feedback echo, speed change by resampling, and second-order low-pass and high-pass filters.

ANALYSISSee the sound

A radix-2 FFT drives a short-time Fourier transform. Spectrograms render to BMP on a log-frequency axis, and PEAKFREQ finds the loudest pitch.

SAFETYUndo anything

Every edit works on a copy. If a command fails halfway, the clip is untouched, and the last 20 edits can be undone.

WORKFLOWLive or scripted

Type commands interactively, or run a whole script file with comments. GitHub Actions builds and tests it on Linux, Windows and macOS.

03

Under the hood

The three parts that took the most thought, with the actual C++ from the repository.

Fast Fourier Transform

A naive Fourier transform compares the signal against every frequency, which costs O(N²). Cooley–Tukey splits it into even and odd halves recursively, so it costs O(N log N).

X[k] = E[k] + w·O[k], X[k+N/2] = E[k] − w·O[k], w = e^(−2πik/N)

The implementation is iterative: reorder the input by bit-reversed index, then merge blocks of size 2, 4, 8 and so on. The unit tests compare it against a naive DFT to 10⁻⁹.

// combine sub-transforms of size len/2 into size len
for (std::size_t len = 2; len <= n; len <<= 1) {
    const double angle = 2 * kPi / len * (inverse ? 1 : -1);
    const std::complex<double> wLen(std::cos(angle), std::sin(angle));
    for (std::size_t i = 0; i < n; i += len) {
        std::complex<double> w(1);
        for (std::size_t k = 0; k < len / 2; ++k) {
            const auto even = a[i + k];
            const auto odd  = a[i + k + len / 2] * w;
            a[i + k]           = even + odd;   // butterfly
            a[i + k + len / 2] = even - odd;
            w *= wLen;
        }
    }
}

Biquad filters

Low-pass and high-pass filters are second-order IIR filters: each output sample mixes the last two inputs and the last two outputs.

y[n] = b0·x[n] + b1·x[n−1] + b2·x[n−2] − a1·y[n−1] − a2·y[n−2]

The coefficients come from Robert Bristow-Johnson's Audio EQ Cookbook, with Q = 1/√2 for a flat (Butterworth) passband. In the tests, an 8 kHz tone through an 1 kHz low-pass drops below 4% of its level.

// Direct Form I, one filter state per channel
for (auto& ch : clip.channels()) {
    double x1 = 0, x2 = 0, y1 = 0, y2 = 0;
    for (float& s : ch) {
        const double x0 = s;
        const double y0 = b0 * x0 + b1 * x1 + b2 * x2
                        - na1 * y1 - na2 * y2;
        x2 = x1; x1 = x0;
        y2 = y1; y1 = y0;
        s = static_cast<float>(y0);
    }
}

Reading WAV files

A WAV file is a RIFF container: a list of tagged chunks. The reader walks every chunk, keeps the format and the samples, and skips the rest, such as metadata.

Every format is decoded into 32-bit floats between −1 and 1, so no effect has to care whether the file was 8-bit, 24-bit or float. 24-bit samples need manual sign extension.

// walk the RIFF chunks; only "fmt " and "data" matter
while (pos + 8 <= data.size()) {
    const uint8_t* id = data.data() + pos;
    std::size_t size = readLE32(data.data() + pos + 4);
    std::size_t body = pos + 8;

    if (std::memcmp(id, "fmt ", 4) == 0)      parseFormat(body);
    else if (std::memcmp(id, "data", 4) == 0) samples = data.data() + body;

    pos = body + size + (size & 1);  // chunks are padded to even size
}
04

Commands

Times are in seconds. Commands are case-insensitive, # starts a comment, and file names with spaces can be quoted.

CommandWhat it does
Files
LOAD <file.wav>Open a WAV file
SAVE [file.wav]Save as 16-bit PCM (to the current file if no name is given)
TONE <hz> <seconds> [rate]Generate a sine wave
INFODuration, sample rate, channels and peak level
Editing
CROP <start> <end>Keep only this part
CUT <start> <end>Remove this part
APPEND <file.wav>Add another file at the end
MIX <file.wav> [at]Overlay another file, optionally starting at a time
SILENCE <at> <length>Insert silence
MONOMix all channels down to one
Effects
VOLUME <factor>Scale the volume, e.g. 0.5 for half as loud
NORMALIZE [peak]Scale so the loudest sample reaches the peak (default 0.99)
REVERSEPlay backwards
SPEED <factor>Change speed and pitch; 2 is twice as fast
FADEIN <s> / FADEOUT <s>Linear fades
ECHO <delay> <decay>Feedback echo, e.g. ECHO 0.3 0.5
LOWPASS <hz> / HIGHPASS <hz>Second-order biquad filters
Analysis
SPECTROGRAM <file.bmp> [fft]Render a spectrogram image
PEAKFREQPrint the dominant frequency
UNDO, HELP, EXITUndo the last edit, list commands, quit
05

Build it

Needs CMake 3.14 or newer and any C++17 compiler: GCC, Clang or MSVC.

Compile and test

$ git clone https://github.com/Cocktail99/CLI_Audio_Editor
$ cd CLI_Audio_Editor
$ cmake -S . -B build
$ cmake --build build
$ ./build/tests
All tests passed

Run

$ ./build/audio_editor                    # interactive
$ ./build/audio_editor examples/demo.txt  # script
> LOAD song.wav
Loaded song.wav (3:12.40, 44100 Hz, 2 ch)
> CROP 30 60
> SPECTROGRAM song.bmp
